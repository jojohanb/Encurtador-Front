# Encurtador de Links (Front)

Nosso projeto em react que serve como um site para encurtar URLs longas, gerenciar links criados e copiá-los facilmente.  
O frontend usa uma **API REST** hospedada localmente (`http://localhost:3333/api`).


## Tecnologias Utilizadas

- **React** – Biblioteca principal de UI  
- **Vite** – Ferramenta de build e servidor de desenvolvimento  
- **JavaScript** - Lógica do código
- **CSS3** – Estilização 
- **Fetch API** – Comunicação com o backend  

## Funcionalidades

- Encurtar links longos inserindo uma legenda e uma URL  
- Listar todos os links encurtados vindos do backend  
- Exibir número de cliques e URL curta gerada  
- Copiar a URL curta com um clique  
- Interface limpa e responsiva  

## Como rodar
- 1- Instale as dependêcias com **npm install**
- 2- Execute o servidor com **npm run dev**
